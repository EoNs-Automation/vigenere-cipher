# Vigenère Cipher

A simple tool that encrypts and decrypts messages using the Vigenère cipher.

## Features

- Encrypt messages with a custom passcode
- Decrypt messages with the same passcode
- Supports letters and preserves spaces/punctuation
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://vigenere-cipher-66666g.netlify.app/)

## How to Use (Python)

1. Run the script
2. Choose Encrypt or Decrypt
3. Enter your passcode
4. Enter the message

## Example

**Original message:**  
`Hello World`

**Passcode:**  
`python`

**Encrypted:**  
`wliiz xcrld`
